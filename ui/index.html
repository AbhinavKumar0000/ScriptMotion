How it works

  1. 1 You enter a topic (manual input).
  2. 2 LLM writes a teaching script (narration + visual beats).
  3. 3 Remotion component generated from the script.
  4. 4 TypeScript validates before rendering.
  5. 5 Remotion renders the MP4.

API keys live in .env. Only the selected provider is called.

Quality rules: No CSS transitions, no glow filters, narration-synced timing, ≤7 words on screen, body text ≥32px, one consistent metaphor.
